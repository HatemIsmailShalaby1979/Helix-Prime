## Method

The shipped engine (`engines/wfm/src/erlang_c.py`, pre-rewrite) was driven
through its own API and compared against three independent formulations of
textbook Erlang C, which agree with each other to a worst spread of 2.2e-16:

1. **Erlang B forward recursion** — `B(0,A)=1; B(n,A)=A·B(n-1,A)/(n+A·B(n-1,A))`;
   `C(N,A) = N·B/(N−A·(1−B))`.
2. **Factorial closed form** — the formulation of
   `shared_utils/erlang_c.py` in
   `github.com/HatemIsmailShalaby1979/wfm-forecasting-calculator`:
   `C = [A^N/N!·N/(N−A)] / [Σ(A^k/k!) + A^N/N!·N/(N−A)]`. Valid for small N
   only: at N=200 the float division overflows (`OverflowError`), which is
   precisely why the fixed engine uses the recursion.
3. **Stable 1/B recursion** — the variant already present in this repository
   (`telemetry_simulator.py:_erlang_c`).

The reference repo's self-test values were reproduced exactly by the
independent computation before any comparison: C(10, 8.5) = **0.5299**;
SL(12, 8.5, t=20 s, AHT=180 s) = **86.70%**; ASA(12, 8.5, 180 s) = **10.09 s**;
occupancy(8.5, 12) = **70.83%**; required_agents(100 calls, 180 s AHT,
30-min interval, 80/20) = **14**.

All runs: Python 3.12.10, `.venv-py312`, repo root `E:\Helix-Prime`.

## What changed in the engine (summary)

- Erlang C via the stable Erlang B forward recursion (no factorials).
- Unstable queue made explicit: A ≥ N → Pw = 1, ASA = ∞, SL = 0.
- Service level defined against a documented answer threshold
  (`target_answer_time`, default 20 s — the classic 80/20 rule).
- ASA corrected to `C·AHT/(N−A)` (the old form omitted the C factor).
- `traffic_intensity` is the offered load in Erlangs; `utilization` is A/N
  (previously both carried per-agent utilisation).
- Removed: the fake `confidence_interval` (flat `0.05·agents` band), the
  never-read `confidence_level` parameter, the global
  `warnings.filterwarnings("ignore")` import side effect, the mojibake
  docstring glyphs.
- Provenance: formulation from wfm-forecasting-calculator
  (`shared_utils/erlang_c.py`), re-expressed on the recursion; cited in the
  module docstring and pinned by `tests/test_wfm_erlang_c.py`.
