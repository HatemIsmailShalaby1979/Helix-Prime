The operations core of Helix Codex.

A local-first platform with six business engines (WFM, RTA, CX, B2B, Personnel, CRM) and nine AI agents routing by content. A governed FastAPI spine (helix-api) with identity, RBAC, approvals, kill switch, and audit chain — enforced, not promised.

Where it stands: Internal self-approval only (CONTROLLED_PILOT_READY, approver operator-pilot-consent). This is not a third-party pilot. Production is NOT_READY with nine production-only gates red by design: signed production evidence, certified data isolation, external observer audit, production deployment architecture, disaster recovery evidence, operational ownership, incident on-call ownership, security review, and legal privacy review. Live connectors disabled.

The public demo

A stranger can sign in and drive the governed path end to end. GitHub OAuth through Supabase Auth (PKCE, S256) lands the visitor on a session holding exactly one permission, ops.view — not a shared password, and not an ops_gm in disguise. They submit four numbers and get a real Erlang C workforce forecast from the same gate, workflow record, and audit trail the internal pilot uses.

The governance is enforced, not described. A fail-closed gate (evaluate_gate) evaluates every submission before any engine is called, against the role's cost limit, data classification, confidence score, and engine ownership. Every record is provenance-tagged simulated_realistic by the server — no request can set that, and a request carrying a field it does not own is refused with 400 rather than silently stripped. Rate limits bound every route a stranger can reach, keyed on the resolved visitor. And a read-only audit trail at /app/ops/audit/{correlation_id} lets a visitor inspect the actual decision chain behind their own run.

No demo address is published here. The app runs behind a Cloudflare Worker whose origin is a Quick Tunnel that is not left running between sessions and whose hostname rotates on every restart — so a link would land on an offline page. The measured evidence, the redirect chain and a captured run with its correlation id, lives in the repository README. To see it live, open an issue on the repository and a session will be started.

  • No certified data isolation.
  • No signed security review.
  • No legal privacy review.

Run it

Canonical: helix-api (FastAPI spine, bare uvicorn, binds 127.0.0.1:8000). Secondary: helix-cockpit (Streamlit, read-only diagnostic surface). Ollama is optional; without it the system runs in deterministic offline mode and reports the limitation. No cloud dependency. Everything runs on your machine.
