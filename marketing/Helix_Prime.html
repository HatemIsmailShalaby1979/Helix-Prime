Public alpha

One unified operations system.

Helix Prime contains six business engines, four AI agents, content-based request routing, a local Ollama model connection, and a Streamlit Operations Cockpit.

Components

Agents

SAMI, SUBY, PHILI, and WILI connect to a local Ollama model.

Orchestrator

Requests are routed according to their content.

Operations Cockpit

A Streamlit interface for the operations system.

Business engines

  • WFM/Erlang C
  • RTA
  • CX Churn Sentinel
  • B2B Onboarding
  • Personnel
  • CRM
Status

Alpha, not overstated

The public repository is real and its core modules are present. Full agent inter-communication through the live UI is still pending, along with incremental work on automated test coverage and CI polish. There are no client deployments or production enterprise deployments to claim.

Local setup

Run the cockpit

Requires Python 3.13+. Ollama is optional for local model inference.

python -m venv .venv
.venv\\Scripts\\activate
pip install -r cockpit/requirements.txt
python launch.py --dash-only

Open http://localhost:8501.
