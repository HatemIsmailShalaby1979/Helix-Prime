A unified operations system with AI agents and business engines.

Helix Prime brings six business engines, four AI agents, content-based orchestration, a local Ollama model connection, and a Streamlit Operations Cockpit into one public repository.

The system

Operational capabilities in one repository

The system is organized around domain-specific engines and agents. Requests are routed by content, and the cockpit provides the current interface to the operations system.

Four AI agents

SAMI, SUBY, PHILI, and WILI are connected to a local Ollama model.

Operations Cockpit

A Streamlit interface for the Helix Prime operations system.

Content-based routing

The orchestrator routes requests according to their content.

One unified system

Helix Prime is one system. The old Helix_OPS, Helix_Sonar, and Helix_Watch names are not part of this project.

Current status

Alpha, documented honestly

Core modules, the agents, the engines, the orchestrator, and the Operations Cockpit are present. Full agent inter-communication through the live UI is still pending. Automated test coverage and CI polish remain ongoing work. There are no client deployments or production enterprise deployments to claim.

Run locally

Start the cockpit

Requires Python 3.13+. Ollama is optional for local model inference.

python -m venv .venv
.venv\\Scripts\\activate
pip install -r cockpit/requirements.txt
python launch.py --dash-only

The dashboard runs at http://localhost:8501.
